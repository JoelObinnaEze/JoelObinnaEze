## What I'm working on

### FPGA 2D Graphics Accelerator and Memory System

`SystemVerilog` `FPGA` `SDRAM` `SPI` `RP2040`

Designing a SystemVerilog graphics accelerator with:

- Rectangle and sprite rendering
- Command buffering and 640 × 480 video output
- SDRAM-backed RGB565 framebuffer
- Burst transfers, FIFOs, and memory arbitration
- SPI command interface for an RP2040
- Self-checking SystemVerilog testbenches
- Synthesis, place-and-route, timing analysis, and waveform debugging

### SOAR Avionics Software

`STM32` `C/C++` `FreeRTOS` `UART` `SPI` `GPIO`

Contributing to STM32-based avionics firmware and hardware/software integration, including embedded telemetry, FreeRTOS task communication, peripheral work, and Git-based team development.
